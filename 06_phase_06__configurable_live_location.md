# Phase 06 - Configurable Live Location

> I AM HERE emergency safety application.

## Status

Completed

## Objective

Build a configurable, high-resilience live location engine combining battery-adaptive GPS intervals, native foreground execution with WakeLock, noise filtering for erratic cell-tower bounces, and an offline queue with batch sync to ensure zero location loss during network drops.

## Implemented Architecture

### 1. Configurable & Battery-Adaptive GPS Tracking (`EmergencyLocationService.kt`)
- `FusedLocationProviderClient` configured with `PRIORITY_HIGH_ACCURACY`.
- **Sampling Intervals**:
  - High-Urgency Emergency Active: 5 seconds interval, 3 seconds fastest interval, 1 meter displacement.
  - Low Battery (< 15%): Automatically throttles to 15 seconds to prevent device shutdown during prolonged distress.
- Holds `PARTIAL_WAKE_LOCK` (`"IAmHere:EmergencyLocationLock"`) ensuring CPU stays awake even when screen is locked.
- Telemetry attributes: Latitude, Longitude, Accuracy radius, Speed (m/s), Heading/Bearing, Altitude, Timestamp, and Battery percentage.

### 2. Accuracy Filtering & Noise Reduction
- Readings with horizontal accuracy radius $> 60\text{ meters}$ (e.g. coarse cell-tower triangulation bounces) are filtered out, preserving map marker stability and preventing false trail jumps.

### 3. Offline Location Queue (`OfflineLocationQueue.kt`)
- If the victim enters an elevator, basement, or dead zone:
  - Location points continue to be generated by GPS sensors.
  - Points are enqueued in an in-memory thread-safe buffer (up to 500 ordered points).
- Once network connectivity is restored:
  - The queue automatically drains and flushes all buffered points to `POST /api/sos/:token/locations/batch`.

### 4. Backend Batch Ingestion (`POST /api/sos/:token/locations/batch`)
- Ingests chronological arrays of buffered GPS points.
- Sorts and appends breadcrumbs to session history without duplicate timestamps.
- Updates session `lastLocation` and battery level from the latest valid point in the batch.
